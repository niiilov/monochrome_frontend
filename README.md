# MONO

Фронтенд кибердайджеста для кейса №1. В проекте есть лендинг, демонстрационная регистрация и дашборд для подготовки выпуска.

## Локальный запуск

Нужен Node.js 20.9 или новее.

```sh
npm ci
npm run dev -- --webpack --port 3107
```

- [Лендинг](http://127.0.0.1:3107/)
- [Регистрация](http://127.0.0.1:3107/auth)
- [Дашборд](http://127.0.0.1:3107/dashboard)

Дашборд работает на демоданных. Обработка публикаций и рассылка показаны как демонстрационные сценарии. Имя и почта демопрофиля хранятся в текущей вкладке.

## Проверка

```sh
npm run build -- --webpack
npm run typecheck
```
