# MONO

Фронтенд MONO на Next.js для подготовки дайджестов по кибербезопасности. Лендинг открывается на `/` на русском. Для остальных языков используются отдельные адреса, например `/en` и `/ar`. Старый путь `/eu` открывает русскую версию.

Для локального запуска нужен Node.js 20.9 или новее.

```sh
npm ci
npm run dev -- --webpack --port 3107
```

Откройте [лендинг](http://127.0.0.1:3107/). Для проверки выполните `npm run build -- --webpack`, затем `npm run typecheck`.

Тексты всех языковых версий находятся в `app/copy.ts`, список языков — в `app/locales.ts`. Цвета тем и параметры анимации заданы в `app/globals.css`. Выбранная тема сохраняется в браузере.

## Дашборд и Go API

Бэкенд берётся из ветки `main` репозитория [niiilov/cyber-digest](https://github.com/niiilov/cyber-digest/tree/main).
Для локальной проверки запустите его из корня бэкенда в отдельном терминале:

```sh
DIGEST_ADDR=127.0.0.1:8080 ALLOWED_TEST_RECIPIENTS=test@example.com go run ./cmd/digestd --mock
```

Откройте [локальную страницу входа](http://127.0.0.1:3107/auth), создайте демопрофиль с кодом `123456` и перейдите в дашборд. Нажмите «Собрать дайджест». По умолчанию используется учебный набор Go-репозитория за 7 ноября 2026 года.

После обработки откройте «Последний выпуск». В журнале указана причина отбора или исключения каждой публикации. Скачивание материалов выгружает дайджест, пост, письмо, журнал и отчёт одним архивом.

Для своих публикаций загрузите JSON, JSONL или CSV до 8 МБ и задайте конец периода по Москве. Сервис обработает предыдущие 24 часа. Формат записей и пример файла есть в [инструкции](http://127.0.0.1:3107/dashboard/guide#own-data).

Если Go API слушает другой адрес, задайте `DIGEST_API_URL` в `.env.local` фронтенда. Адрес указывается без пути `/api/v1`. Браузер обращается к серверу Next.js, а тот передаёт запросы в Go API.

Флаг `--mock` запускает обработку без внешней модели. Учебный выпуск в этом режиме может содержать ноль событий. Для запуска с моделью настройте её на стороне Go по инструкции бэкенда. Кнопка «Проверить отправку» на странице письма проверяет адреса из `ALLOWED_TEST_RECIPIENTS` без доставки письма. Демопрофиль хранится в браузере.
