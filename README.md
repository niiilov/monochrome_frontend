# MONO

Фронтенд MONO на Next.js для подготовки дайджестов по кибербезопасности. Лендинг открывается на `/` на русском. Для остальных языков используются отдельные адреса, например `/en` и `/ar`. Старый путь `/eu` открывает русскую версию.

## Локальный запуск

Для локального запуска нужен Node.js 20.9 или новее.

```sh
npm ci
npm run dev -- --webpack --port 3107
```

Откройте [лендинг](http://127.0.0.1:3107/). Для проверки выполните `npm run build -- --webpack`, затем `npm run typecheck`.

Тексты всех языковых версий находятся в `app/copy.ts`, список языков — в `app/locales.ts`. Цвета тем и параметры анимации заданы в `app/globals.css`. Выбранная тема сохраняется в браузере.

## Дашборд и Go API

Бэкенд находится в ветке `main` репозитория [niiilov/cyber-digest](https://github.com/niiilov/cyber-digest/tree/main). Для входа, работы с источниками, сбора и рассылки выпусков нужен запущенный Go API. Следуйте инструкции бэкенда для запуска `monod`.

```dotenv
# .env.local во фронтенде, если API запущен локально на порту 8080
DIGEST_API_URL=http://127.0.0.1:8080
APP_PUBLIC_URL=http://127.0.0.1:3107
```

Браузер обращается к серверу Next.js, который передаёт запросы в Go API. Указывайте `DIGEST_API_URL` без пути `/api/v1`.

Откройте [страницу входа](http://127.0.0.1:3107/auth?mode=signin) и войдите в аккаунт, чтобы перейти в дашборд. На странице «Главное» можно собрать выпуск из учебного набора, файла или добавленных сайтов.

Для своих публикаций загрузите JSON, JSONL или CSV до 8 МБ и задайте конец периода по Москве. Сервис обработает предыдущие 24 часа. Формат записей и пример файла есть в [инструкции](http://127.0.0.1:3107/dashboard/guide#own-data).

После обработки откройте «Дайджест». Причины отбора и исключения публикаций видны в «Журнале». Выпуск и отчёт можно скачать одним архивом.
